使用说明与限制

绿色日期表示有文章。2026年11月19—21日仅有历史目录摘要，需要重新导入完整原文；没有原文就不冒充完整收录。后续文章需由 ChatGPT 每期另附一个可导入 JSON 文件。

网页不能直接读取 ChatGPT 聊天中的图片组件或自动下载聊天附件。若文章附有公开图片网址，图片可以在网站显示；本地照片可在其他服务上传成公开图片链接后嵌入。导入的文章仅保存在当前浏览器，清理站点数据可能丢失；使用“导出网站文章库”才能发布给所有设备。

旧版 GitHub Actions 的“每日自动发布十二维”属于另外付费调用 API 的流程，建议在仓库 Actions 中关闭该 Workflow。这个网站版本本身不调用付费 API。
